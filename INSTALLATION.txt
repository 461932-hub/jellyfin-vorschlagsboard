Vorschlagsboard 2.0.0.5 für Jellyfin 12.4

Normale Nutzer sehen als Autor bei jedem Vorschlag „Anonym“.
Jellyfin-Administratoren sehen die gespeicherten Benutzernamen.
Das gilt auch für bereits vorhandene Vorschläge.

Update über Jellyfin
1. Verwaltung -> Plugins -> Katalog -> Vorschlagsboard öffnen.
2. Version 2.0.0.5 installieren.
3. Den Jellyfin-Container in CasaOS neu starten.
4. Die Jellyfin-Webseite neu laden und die Handy-App neu öffnen.

Repository-URL
https://raw.githubusercontent.com/461932-hub/jellyfin-vorschlagsboard/main/manifest.json

Die Anonymisierung wird im Server für jede API-Antwort angewendet.
Die gespeicherten Namen stehen Administratoren weiterhin zur Verfügung.
Geprüft mit echten Konten auf einem isolierten Jellyfin-12.4-Server,
einschließlich Listen, Seitenauswahl, Abstimmungen, Status und Browseranzeige.
